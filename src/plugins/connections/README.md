# connections

Connections are environment variables: the read-only Connections view and `gtm connections list | set | delete` for local keys.

- Line budget: 300 lines of TypeScript (`npm run lines` in the gtm repository), reviewed at every release.
- Commands and docs: `gtm connections`; docs: `connections`.
- Eject it with `npx gtm eject connections` to edit a copy in `plugins/connections/`; `npx gtm diff connections` shows upstream changes.
