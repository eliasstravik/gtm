# context

The Context view (the console's home): `context/**/*.md` and the company's skills, read-only, and the AGENTS.md lines on context.

- Line budget: 280 lines of TypeScript (`npm run lines` in the gtm repository), reviewed at every release.
- Docs: `context`.
- Eject it with `npx gtm eject context` to edit a copy in `plugins/context/`; `npx gtm diff context` shows upstream changes.
