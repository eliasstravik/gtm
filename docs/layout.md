# Layout

A gtm project is one Next.js app in one repo and one Vercel project per company. Every file is the company's
except the managed block in `AGENTS.md` (`<!-- BEGIN:gtm -->` … `<!-- END:gtm -->`), which
`npx @eliasstravik/gtm init` refreshes.

| Path | Holds |
| --- | --- |
| `AGENTS.md` | the company's standing instructions, plus the managed block |
| `CLAUDE.md` | `@AGENTS.md` |
| `context/` | Markdown, any shape: `company.md`, `icps/`, `personas/`, `voice.md`, … |
| `workflows/` | Workflow SDK workflows; `workflows/index.ts` exports `{ <name>: workflowFn }` (the registry) |
| `db/schema.ts` | Drizzle schema for workflow-owned tables in `public` |
| `db/migrations/` | generated by `npm run db:generate` (see data.md) |
| `proxy.ts` | `gtmProxy`; keep the matcher exactly as the starter wrote it |
| `public/_gtm/probe.txt` | `gtm-probe-v1`; the fail-closed and Save checks request it |
| `app/layout.tsx` | wraps every page in the Console shell |
| `app/[[...path]]/page.tsx` | the built-in views |
| `app/api/gtm/[...path]/route.ts` | `gtm({ workflows })`: Console reads, start, runs, cron, Connections save |
| `app/api/hooks/<sender>/route.ts` | inbound webhooks (webhooks.md) |
| `.agents/skills/` | the company's own project skills, one `<name>/SKILL.md` each |
| `.claude/skills` | symlink to `../.agents/skills`; how Claude Code sees the company's skills |
| `agent/` | optional Slack agent, added by `npx @eliasstravik/gtm init --slack` (slack.md) |
| `.env.example` | every connection name with a one-line comment (connections.md) |
| `vercel.json` | crons, each pointing at `/api/gtm/cron/<workflow>` (workflows.md) |
| `next.config.ts` | `withGtm({})` from `@eliasstravik/gtm/next` |
| `package.json` | scripts `dev` (`gtm dev`), `build` (`gtm migrate && next build`), `db:generate`, `db:migrate` |

Gitignored: `.env*.local`, `.gtm/` (local database), `.workflow-data/` (local runs), `.vercel/`, `.next/`,
`node_modules/`.

## Where things go

- Company know-how (company facts, ICPs, personas, voice, house style) is Markdown under `context/`.
- Project skills go in `.agents/skills/` only. Where symlinks fail (Windows without developer mode) `init`
  copies instead, and `npx @eliasstravik/gtm check` warns that the copies must be kept in sync.
- The `gtm` skill that set this project up is never installed into it.
- Lasting results live in workflow-owned tables in `public`, not in run history.
- Reserved first path segments: `context`, `workflows`, `data`, `connections`, `api`, `eve`, `_gtm`.

## What the Console reads

- Sidebar: the company name is the first `# ` heading of `context/company.md` (else "GTM"); under it the
  environment badge (Local, Preview, Production; amber "Updating…" while a saved key goes live); then Context,
  Workflows (with Runs), Data and Connections (with a count of keys not set here). Below 1024px wide the sidebar
  folds behind a menu button.
- Context: every `context/**/*.md` sorted by path; under "Skills", `AGENTS.md` and every
  `.agents/skills/*/SKILL.md`. Read-only; hosted, each file links to GitHub. Only `.md` files show.
- Workflows: the names in `workflows/index.ts`, the schedules in `vercel.json`, and each one's last run; Runs
  lists every run, filtered by workflow, status and time, from the Workflow SDK's own run store. Neither touches
  the database; both refresh every few seconds while a run is going.
- Data: the tables in schema `public` (data.md). Connections: the names in `.env.example` (connections.md).
- Hosted, `withGtm` ships `context/**`, `.agents/skills/**`, `AGENTS.md`, `.env.example` and `vercel.json`
  with every route, so the live Console shows the last deployed commit.

## Keeping the layout

`npx @eliasstravik/gtm check` reports a broken layout, an outdated managed block, a changed `proxy.ts` matcher
and a broken registry, each with its fix. Re-running `npx @eliasstravik/gtm init` restores only the symlinks,
`proxy.ts`, the two `app/` files above with `[...path]` in their names, `public/_gtm/probe.txt` and
`.gitignore`, and refreshes the managed block; it never recreates deleted context or other files.
